# Python Voice Assistant

## Project Description
This is a Python Voice Assistant project developed as part of the Oasis Infobyte internship tasks. It allows users to interact with a computer using voice commands.

## Features
- Voice input using speech recognition
- Text-to-speech responses
- Greeting, date, and time commands
- Web search
- Weather information using OpenWeatherMap API
- Email sending
- Reminders
- General knowledge responses
- Custom voice commands
- Error handling

## Technologies Used
- Python
- SpeechRecognition
- pyttsx3
- Requests
- Python-dotenv
- OpenWeatherMap API
- Wikipedia API
- SMTP for email sending

## Installation and Setup
1. Install Python on your computer.
2. Install the required dependencies:

   `pip install -r requirements.txt`

3. Create a `.env` file using `.env.example` as a template.
4. Add your own API key and email configuration to `.env`.
5. Start the application:

   `python main.py`

## Configuration
The application uses environment variables for weather and email configuration. Never share API keys, app passwords, or other secrets publicly.

## How to Use
Run the application and speak commands into your microphone. The assistant processes the commands and responds using speech.
